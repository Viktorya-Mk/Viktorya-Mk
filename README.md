## 🧭 About this space

This is where I keep my cybersecurity work: hands-on labs, investigation write-ups and a few tools I've built along the way. I come from web development, so I like to understand how things are built before I look at how they break.

Everything here is a work in progress and keeps growing as I learn.

**What I'm exploring**
- **Web application security** ~ finding and explaining flaws such as XSS, IDOR and broken authentication
- **OSINT** ~ metadata, geolocation and open source investigation methods
- **Threat intelligence** ~ analyst-style case studies from public reporting
- **Investigation methodology** ~ structured analysis, source verification, clear reporting
